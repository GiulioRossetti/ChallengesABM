# Example Scripts

This folder contains small runnable scripts that show different model presets and configuration patterns.

## Available Examples

- `visualize_results.py`: runs a baseline simulation and saves the standard plots.
- `baseline_default.py`: minimal configuration using the default Beta priors and random seeding.
- `high_visibility_cascade.py`: a more contagious scenario with stronger appeal and easier diffusion.
- `defensive_counteraction.py`: a scenario where risk perception and counteraction are emphasized.
- `explicit_seeds_and_traits.py`: shows how to choose initial seeds explicitly and override the trait distributions.
- `topology_visual_presets.py`: compares a clustered network with a sparse random graph using the same plotting preset.

Run any script from the project root, for example:

```bash
python examples/baseline_default.py
```
